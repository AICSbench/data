# AICSbench data

Benchmark runs submitted to [AICSbench](https://github.com/AICSbench/aicsbench),
the open benchmark for AI coding agents across languages and frameworks.

- Submissions arrive as pull requests, made with `aicsbench submit` after a run.
- CI validates each submission and exports JSON for the public site,
  [AICSbench/web](https://github.com/AICSbench/web).

This repository is being set up in Phase 5. See
[docs/phase-5](https://github.com/AICSbench/aicsbench/tree/main/docs/phase-5)
in the main repository for the plan.
